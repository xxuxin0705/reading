# 正文朗读（SillyTavern 插件）

正文台词按情绪朗读：在酒馆正文里给台词挂上 ▶（播放）↻（重新生成）🎭（调演法）。

## 安装
把整个 `storyvoice-reader` 文件夹放到：
`SillyTavern/public/scripts/extensions/third-party/storyvoice-reader/`
然后刷新酒馆，在「扩展」里确认「正文朗读」已启用。

## 打开
- 魔法棒菜单 → 🔊 正文朗读
- 或者「扩展」面板 → 正文朗读 → 打开正文朗读设置

## 第一次用
1. 语音渠道：选渠道（Fish / MiniMax / OpenAI / 豆包 / IndexTTS / 第三方 OpenAI 兼容），填接口地址和 Key。
2. 角色音色库：添加角色（名字要和正文里 [[名字]] 标的一样，别名可以写昵称），填音色 ID。
   - 默认「所有聊天」共用，换聊天、换回来都还在。
   - 不同作品同名角色要不同声音时，才选「只在当前角色卡」。
   - 自己的台词：添加一个角色并打开「这是我（用户）」。
3. 情绪分析：简单 / 深度 / 手动三选一。

## 数据放在哪
- 设置、Key、角色音色库：酒馆的插件设置（settings.json 里的 `storyvoice-reader`）。
- 深度分析结果、语音收藏（含音频）：只存在这台设备的浏览器里。


## 配套正则（可选，推荐）
导入 `正文朗读-发送时去掉标记.json`：发给 AI 时去掉正文里的 [[名字|语气]] / [[环境:xx]] 标记，不影响显示和朗读。

## 环境声扩展
环境声现包含原有 9 类和新增 32 类，均通过 WebAudio 实时合成，不需要额外音频文件。支持简单模式标记 `[[环境:forest]]`、深度分析自动选择与手动逐句选择。合成环境声为拟声效果，并非真实采样。
