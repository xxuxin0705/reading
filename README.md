# 正文朗读（SillyTavern 插件）

正文台词按情绪朗读：在酒馆正文里给台词挂上 ▶（播放）↻（重新生成）🎭（调演法）。

## 安装
把整个 `storyvoice-reader` 文件夹放到：
`SillyTavern/public/scripts/extensions/third-party/storyvoice-reader/`
然后刷新酒馆，在「扩展」里确认「正文朗读」已启用。

## 打开
- 魔法棒菜单 → 🔊 正文朗读
- 或者「扩展」面板 → 正文朗读 → 打开正文朗读设置

## 第一次用
首页有四个入口：👥 角色库、🔌 API 设置、🎭 情绪分析、⭐ 语音收藏。
1. API 设置：选渠道（Fish / MiniMax / OpenAI / 豆包 / IndexTTS / 第三方 OpenAI 兼容），填接口地址和 Key；深度分析用的模型接口也在这里。
2. 角色库：先点「添加说话人」，再选是「我」还是「角色」，给每个人选渠道、填音色 ID、打标签（可按标签筛选）。
   - 名字要和正文里 [[名字]] 标的一样，别名可以写昵称。
   - 「我」= 你自己的台词，每个聊天一个。
   - 页面最下面是 NPC：选「只读配了音色的人」或「所有说话的都读」；都读时库里没有的人按性别用 NPC 的男 / 女 / 默认音色（可以单独选渠道）。
   - 每个人用自己的渠道时，🎭 逐句调整和深度分析会按这个人的渠道给出它能认的写法（Fish 句中标签、MiniMax 整句情绪、OpenAI / 豆包 / IndexTTS 整句语气说明…），面板里能看到实际发过去的内容。
3. 情绪分析：简单 / 深度 / 手动三选一，环境声和拟声词也在这里。

## 数据放在哪
- 设置、Key、角色音色库：酒馆的插件设置（settings.json 里的 `storyvoice-reader`）。
- 深度分析结果、语音收藏（含音频）：只存在这台设备的浏览器里。


## 配套正则（可选，推荐）
导入 `正文朗读-发送时去掉标记.json`：发给 AI 时去掉正文里的 [[名字|语气]] / [[环境:xx]] 标记，不影响显示和朗读。

## 环境声
提供多种（雨、雪、森林、海边、街道、教室、咖啡馆、剧场掌声、烟花……），全部用 WebAudio 实时合成，不需要额外音频文件。人声嘈杂为柔化的拟声背景，掌声为合成的多人鼓掌声；钟表、脚步、火车按稳定的节奏响；每种环境声都做过响度校准，切换场景音量差不多。支持简单分析标记 `[[环境:forest]]`、深度分析自动选择与在 🎭 里手动选择。合成的环境声是拟声效果，并非真实录音。
